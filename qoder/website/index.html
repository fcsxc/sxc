用 PowerContext 记忆驱动的复习计划与周报助手 —— 让学习、科研更高效

OceanBase 数据库大赛 · Qoder 赛道 核心技术：PowerContext 用 Qoder 开发 Python · Flask

01解决的问题

痛点 1学过就忘，不知道今天该复习什么，考前才突击 —— 复习没有节奏。
痛点 2薄弱点、目标、偏好散落在聊天记录和便签里 —— 工具不会"记得你"，换个会话/设备就丢了。
痛点 3每周要从聊天记录里一条条翻学习记录，手工拼周报 —— 重复又耗时。

02核心功能

🗓️ 今日复习计划

按艾宾浩斯遗忘曲线（1/2/4/7/15/30 天间隔）自动排期，到期自动出现，逾期天数一目了然。

PowerContext：召回档案中的薄弱点，优先排序今日复习

🧠 学习档案（记忆）

目标、薄弱点、偏好、里程碑统一管理，写入 PowerContext 后跨会话、跨重启持久，换个工具也丢不了。

PowerContext：Memory 写入与召回（带版本、可追溯）

✅ 打卡闭环

每次复习点「掌握 ✓ / 又忘了 ✗」，遗忘自动回到第一个复习间隔；「又忘了」的知识点自动记入薄弱点档案。

PowerContext：打卡触发记忆自动写入，后续计划自动复用

📄 自动周报

一键生成周报：本周打卡统计 + 与目标的对照 + 薄弱点提醒，无需再从聊天记录里拼凑。

PowerContext：召回目标/薄弱点，生成「进度 vs 目标」对比

03技术架构与指定技术

浏览器 ── Flask (app/ :5000) ── HTTP ── PowerContext Server (:8000, SQLite)
                │                              │
                └─ 任务/打卡数据 (JSON)          └─ 学习档案 Memory（带版本、跨会话）

PowerContext（OceanBase 开源上下文服务）在项目中的实际作用：

  • 「学习档案」通过 POST /v1/memory/remember 写入、POST /v1/memory/entries/list 召回，POST /v1/context/prepare 按需选取；
  • 「又忘了」打卡自动写入薄弱点记忆，复习计划与周报自动复用；
  • 重启应用后档案依然保留 —— 记忆跨会话持久，可直接通过 HTTP API 核对读写记录。
